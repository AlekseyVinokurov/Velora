# Иконки Velora V Fusion

Выбор находится в **Настройки → Настройки чатов → Иконка приложения**
(существующий экран оформления). V Fusion показана первой, «Классическая»
возвращает прежнюю BlueIcon. Сохранены Anime, Cosmos, Matrix, Neon, Sunset,
Emerald, Midnight, Gold и Crimson. В standalone дополнительно доступны
существующие Vintage, Aqua, Premium, Turbo и Nox. Варианты, у которых в данной
сборке нет launcher-alias, не показываются.

В строке **Иконка уведомлений** независимо выбираются Velora и «Классическая».
Общие уведомления, сообщения и уведомления музыкального плеера используют
выбранный монохромный ресурс. В классическом режиме плеер возвращает `player`,
остальные общие уведомления — `notification`. Значки звонков, состояния микрофона,
геолокации, загрузки/выгрузки, proxy и кнопок действий сохранены. Сообщения,
плеер и resident notification обновляются существующим событием `appIconChanged`;
сервисы плеера и соединения ради смены оформления не перезапускаются.
Кратковременные уведомления переноса файлов и готовности APK применяют выбор
при следующем создании/обновлении уведомления.

## Ресурсы и происхождение

Основной референс — отдельный файл `Неоновый музыкальный логотип V.png`
(1254 × 1254, RGB, с белым внешним полем). Презентации целиком не используются.
`Белая иконка уведомления Velora-2.png` (1536 × 1024, RGBA) содержит чёрный фон
и свечение; это образец формы, а не готовый Android smallIcon.

Геометрия обведена вручную в [design/velora-v-fusion.svg](design/velora-v-fusion.svg).
Android использует самостоятельные VectorDrawable foreground, background и
monochrome. Подложка заполняет весь adaptive layer, без встроенной маски или
белых полей. Все элементы foreground лежат внутри центрального безопасного
круга диаметром 66 dp на слое 108 dp. Окончательную форму задаёт launcher.
Разметка соответствует [документации Android об adaptive icons](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive).

`drawable/velora_notification.xml` — отдельный 24 dp VectorDrawable: белая
непрозрачная V с Play, прозрачный фон, без звуковых полос, градиентов и свечения.
`mipmap-anydpi-v26` подключает цветные adaptive layers; `mipmap-anydpi-v33`
добавляет monochrome. Для API 24–25 есть обычные и круглые PNG в пяти плотностях
(48/72/96/144/192 px), с прозрачными углами.

Ресурсы воспроизводятся без Android SDK:

```sh
# В отдельном Python-окружении с Pillow и CairoSVG:
python3 scripts/generate-velora-icons.py
# Проверки без внешних Python-зависимостей, Android SDK и Gradle:
python3 tests/icons/check_resources.py
python3 tests/icons/run.py
```

Вторая проверка компилирует **только controller и тестовые заглушки** обычным
host `javac`, а затем выполняет production-логику на JVM. Это не Android-сборка
и не доказательство поведения PackageManager на телефоне. Обе проверки также
включены в существующий GitHub Actions перед Android toolchain/build.

## Переключение и миграция

Новые установки получают Velora launcher и Velora smallIcon. Существующее
`launcher_icon_pref/active_icon` продолжает использоваться: сохранённые имена
и ключи aliases распознаются, включая DEFAULT/BlueIcon/DefaultIcon. Если старый
альтернативный alias был явно включён через PackageManager, но preference
отсутствует, он сохраняется. Автоматически включённая прежней версией BlueIcon
без сохранённого выбора переходит на Velora. Новой notification-настройки ранее
не было; её значение по умолчанию — Velora.

На Android 13+ применяется атомарный
[PackageManager.setComponentEnabledSettings](https://developer.android.com/reference/android/content/pm/PackageManager#setComponentEnabledSettings(java.util.List)).
На старых версиях новая компонента включается первой и проверяется, после этого
отключаются остальные aliases. Preference меняется только после успешного
переключения; при ошибке выполняется возврат к предыдущему варианту, UI сообщает
об ошибке. На старых версиях Android launcher может кратковременно показывать
обе иконки, пока обрабатывает последовательные изменения.

При старте приложения и MY_PACKAGE_REPLACED выполняется синхронизация выбора с
aliases. После установки обновления launcher может обновить свой кэш раньше
получения broadcast; после обработки остаётся один активный launcher-alias.
Отключаются только доступные launcher aliases этого приложения. LaunchActivity,
deep links, авторизация и данные аккаунтов не изменяются. Метаданные shortcuts
подключены и к новому alias; динамические и закреплённые ярлыки перепривязываются к выбранному alias без
изменения их intents, подписей и изображений. Новые ярлыки также явно используют
активный alias.

## Ограничение бренда Telegram

[Telegram API Terms, пункт 2.4](https://core.telegram.org/api/terms) запрещает
официальный логотип Telegram в качестве логотипа стороннего приложения.
Сохранение исходных ресурсов и возможности классического оформления не означает
разрешения на такой способ использования. Существующие изображения не удалены,
новые официальные логотипы из внешних источников не добавлены. Для нового
оформления и значения по умолчанию используется собственная V Fusion.
Credits, лицензии, applicationId, API-параметры, подпись и updater не менялись
(в updater заменён только ресурс smallIcon уведомления о готовности APK).

## Приёмка на Pixel 8 с Android 17

- Чистая установка: одна V Fusion, корректные круглые края, V/Play/полосы целиком
  видны. Проверить также системные тематические иконки со светлыми/тёмными обоями.
- Обновление поверх прежнего APK с тем же ключом: проверить явно выбранные
  Classic и альтернативную иконку, затем обновление без сохранённого выбора.
  После завершения broadcast и перезапуска должна оставаться одна иконка.
- Переключить V Fusion → Classic → альтернативная → V Fusion; после каждого
  шага запустить приложение, проверить список приложений и рабочий стол,
  перезапуск процесса и телефона, сохранение аккаунтов и настроек.
- Сменить notification-оформление отдельно от launcher: получить личное/групповое
  сообщение, проверить системную строку состояния, lock screen и свёрнутую шторку.
  У Velora должен быть белый силуэт без цветного квадрата.
- Во время музыки переключить оба вида иконок: воспроизведение продолжается,
  кнопки, обложка и media session работают; Classic возвращает `player`.
- Проверить входящие/исходящие звонки, mute, фоновые загрузки, уведомление об
  обновлении APK, запуск из уведомлений, tg:// deep links и pinned/share shortcuts.

Облачная компиляция подтверждает совместимость исходников и ресурсов, но этот
список требует настоящего устройства. Публикация GitHub Release не выполняется.
