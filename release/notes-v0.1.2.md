В Velora 0.1.2 исправлена конфигурация Firebase Cloud Messaging для фоновых push-уведомлений. Подписанный APK содержит проверенные Firebase-ресурсы для стабильного applicationId; добавлена диагностика этапов получения токена, регистрации в Telegram и обработки push без записи токенов, ключей и содержимого сообщений.

Версия: 0.1.2 (100002), arm64. Публикуется готовый APK из успешного GitHub Actions #42797176789, без пересборки. applicationId и постоянная release-подпись сохранены. Устанавливайте обновление поверх существующей Velora, не удаляя приложение.

CI подтвердил сборку, подпись и Firebase-конфигурацию APK. Реальная доставка сообщений Telegram на Pixel 8 / Android 17 требует отдельной проверки: при свёрнутом приложении, заблокированном экране и переключении Wi-Fi/LTE. Получение FCM-токена и регистрация устройства сами по себе не доказывают доставку.
